# Step 3 — /spec *(per-ticket)*

CodeMaster runs `/spec` at **ticket altitude**, not as one central epic spec. A gnarly
ticket's plan rides with it as `plan.md` inside its ticket folder — not here. There is no
project-level epic spec because CodeMaster grew phase-by-phase rather than as a single epic.

See [backlog/README.md](../../../backlog/README.md) for the ticket-folder layout
(`README.md` + optional `plan.md` + `evidence.md`).
